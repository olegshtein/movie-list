# 🎬 Movies App

Приложение для просмотра фильмов с возможностью сохранять их в избранное.

## 🚀 Функционал

- Просмотр списка фильмов.
- Добавление/удаление фильмов в избранное через иконку ❤️ на постере.
- Фильтрация:
  - `All` — все фильмы
  - `Favorites` — только избранные
- Переход на детальную страницу фильма по клику на постер.
- Удобная структура проекта с использованием Feature-Sliced Design (FSD).

## 🛠️ Технологии

- ⚛️ React
- 📘 TypeScript
- ⚡ Vite
- 🧭 React Router
- 🎨 SCSS Modules
- 🐻 Zustand (глобальное состояние)
- 🏗 Feature-Sliced Design (FSD)
- ✅ ESLint + Prettier + Stylelint

## ▶️ Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск в dev-режиме
npm run dev

# Линтинг (ESLint + Prettier + Stylelint)
npm run lint:fix
```

## 📌 Статус

Проект находится в активной разработке. Возможны изменения в структуре и функционале.
